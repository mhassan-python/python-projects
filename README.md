# Web Scraper

A simple Python web scraper that collects quotes from a website and saves them to a text file.

## Features

- Scrapes quotes from a website
- Uses Python requests
- Uses BeautifulSoup to read the webpage
- Saves scraped quotes to a text file

## Requirements

- Python
- requests
- beautifulsoup4

## How to Run

1. Install the required packages:
   `pip install requests beautifulsoup4`

2. Run the program:
   `py web_scraper.py`

3. The scraped quotes will be saved in a text file.

## Project Files

- `web_scraper.py` - Main web scraper program
- `quotes.txt` - Scraped quotes
- `README.md` - Project documentation
